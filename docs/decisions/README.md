# Decisions

Design questions about FrameReader, the choices considered, and what the owner decided: one file per question, named
`YYYY-MM-DD-what.md` after the day it was decided, so the folder lists them oldest first and parallel pull requests
never edit the same file. Add one whenever a design question is put to the owner (title, then the question, the
choices and the answer, with why).

When a later decision reverses or overtakes one, the older file gets a closing line that says so and links the newer:
`Since YYYY-MM-DD ([newer.md](newer.md)) ...`.

Until 2026-11-07 FrameReader lived in ShotDetector's repository, and its decisions are in
[ShotDetector's docs/decisions/](https://github.com/bisforboman/shotdetector/tree/main/docs/decisions) (those about
FrameReader have "framereader", "frame-reader", "audio", "dash" or "encoding" in their names). The files here from
before that date are copies of the ones this repository's code and docs cite, so their paths still resolve; their
links to the others point there.
